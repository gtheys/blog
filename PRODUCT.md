# PRODUCT.md — Monetize OSS

## What this is
Geert Theys' project family about making money from open source in the age of AI:
- **blog.monetize-oss.com** (this repo) — essays + maintainer interviews, Zola, GitHub Pages
- **monetize-oss.com** (repo: gtheys/monetize-oss.com) — landing page, plain HTML, hotlinks this repo's `style.css`
- **scorecards.monetize-oss.com** — nightly maintenance-health rankings (separate project)

## Audience
Open source maintainers and developers thinking about monetization as AI changes
the economics of code. Technical readers, terminal-fluent, skeptical of hype.

## Thesis (user's own words)
AI means more software written with AI, running on managed backends someone else
profits from — only the interface changes. The opportunity: open source software
on top of services we host, charging for the service, not the code.

## Brand commitments
- Palette: dark `#0f1115` ground, teal `#5eead4` / green `#34d399` accents,
  amber `#febc2e` used sparingly (terminal cursor, primary CTA). Light scheme via
  `prefers-color-scheme` mirror.
- Terminal aesthetic is the signature: the cookie consent widget is a terminal
  window; the landing headline uses a blinking cursor underscore.
- Reference direction (user-pinned, 2026-10): rogerio-style wide dark layout —
  wide content (~72rem), pill badges, big display type, image/screenshot-driven
  sections. Pinned brief beats concept roll.
- Umami analytics (self-hosted via Tailscale Funnel), consent-gated.

## Assumptions (labeled, not interviewed)
- Landing page mode: Persuade (earn attention → blog/scorecards/interviews).
- Blog mode: Read.
